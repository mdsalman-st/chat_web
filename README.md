## 📖 About

**MAJID** is a full-featured, AI-powered EdTech platform built to help Indian students prepare for board examinations — **BSEB (Bihar Board)**, **CBSE**, and **UP Board**. This repository contains the complete frontend application.

The platform provides AI-generated chapter-wise practice tests, handwritten answer sheet evaluation, smart study planners, real-time analytics, and a complete productivity workspace — all accessible for free.

> *"An AI-powered exam engine built by a student, for the students."*

---

## ✨ Features

### 🎓 Student Experience
- **Board Exam Practice** — Chapter-wise & full-length mock tests for BSEB, CBSE, UP Board (2026 pattern)
- **AI-Generated Questions** — Fresh MCQ questions generated by Google Gemini AI for every subject
- **Live Test Environment** — Timed tests with auto-submit, question navigation, and anti-cheat measures
- **Instant Results** — Detailed score breakdown with correct answers and explanations
- **Performance Analytics** — Subject-wise, chapter-wise, and time-based performance tracking
- **Smart Study Planner** — AI-generated daily study plans based on your weak areas
- **Handwritten Answer Evaluation** — Upload handwritten answer sheets for AI-powered subjective evaluation

### 🛠️ Productivity Workspace
- **📝 Notes** — Rich-text note-taking with categories and search
- **✅ Tasks** — Task manager with priorities, deadlines, and progress tracking
- **📅 Calendar** — Academic event calendar with reminders
- **📁 Files** — File manager for organizing study materials
- **💬 Messages** — Internal messaging system
- **🔐 Vault** — Encrypted private notes with passcode protection

### 👨‍🏫 Admin & Teacher Panel
- **Admin Dashboard** — Complete platform management with user stats, audit logs, and system health
- **Subject Admin Panel** — Subject-wise question bank management and paper review
- **AI Health Monitor** — Real-time Gemini API key rotation status and usage analytics
- **Student Feedback** — View and manage student ratings and suggestions
- **Broadcast System** — Send notifications to all students

### 🎨 Design
- **Apple Liquid Glass** design language with glassmorphism effects
- **Fully responsive** — Desktop, tablet, and mobile optimised
- **Dark theme** with deep navy palette and champagne gold accents
- **PWA installable** — Works offline, add to home screen on mobile

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code recommended)
- [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension for local development

### Local Development

```bash
# Clone the repository
git clone https://github.com/mdsalman-st/majid-frontend.git
cd majid-frontend

# Open in VS Code
code .

# Start with Live Server (Right-click index.html → Open with Live Server)
# Or use any static server:
npx serve .
```

### Environment Setup

The frontend connects to the backend API. Update the API base URL in `api.js`:

```javascript
const BASE_URL = 'https://your-backend-url.com';
```
